Install the Native Host

The ReadControl extension needs a small helper app installed on your Mac to save pages to your library. Here's how to set it up.

Option A — Using the macOS app (recommended)

1
Open the ReadControl app
Launch ReadControl from your Applications folder. The app installs the native host automatically on first launch.
2
Choose your library folder
If prompted, pick or create a folder where your saved articles will live.
3
Try saving a page again
Click the ReadControl toolbar button (or press ⌃⇧S) on any page.

Option B — Manual install via Terminal

1
Open Terminal
Find it in Applications → Utilities → Terminal, or press ⌘Space and type "Terminal".
2
Run the install command
Navigate to the ReadControl app bundle and run the native host binary with the install flag:
Open the ReadControl app, then go to Settings → Extensions and click Reinstall Manifest. This runs the install for you.

Still not working? Make sure the ReadControl app has been opened at least once after installation. The host manifest must point to the exact location of the app on disk — if you moved the app, reinstall the manifest from Settings → Extensions.
