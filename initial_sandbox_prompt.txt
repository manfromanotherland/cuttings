You are in a Linux Docker sandbox for the Cuttings repos. extension (Node) and core (Rust) are fully functional — build, test, and lint them as normal. For macos you can run swiftlint and swiftformat and compile non-UI Swift logic, but you cannot build or test the app: there is no Xcode, xcodebuild, or xcodegen, so make all/make dmg/make test won't work here. The core XCFramework build (scripts/build-xcframework.sh, Apple-Darwin targets) also needs a real Mac. Don't spend time trying to build the macOS app — do that work on a Mac.
